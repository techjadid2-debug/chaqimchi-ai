Kamerangizni ulaymiz

Do‘koningizdagi NVR yoki IP kamera shu kompyuter bilan bitta tarmoqda bo‘lishi kerak. Avval tarmoqni tekshiramiz.

Tarmoqdagi kameralarni qidirish

Qidiruv 10–30 soniya davom etadi.

Kamera manzilini kiritish

Kamera topilmasa yoki qaysi biri kerakligini bilsangiz, shu yerdan qo‘shing.

Maslahat: NVR’da faqat ko‘rish huquqiga ega alohida foydalanuvchi yarating. Parol shu kompyuterdan chiqmaydi.

Qo‘shilgan kameralar

Tasvir keldi

Quyidagi rasm haqiqatan shu kameradan olindi. Kerakli joy ko‘rinayaptimi?

Kirish chizig‘ini to‘g‘rilang

Taxminiy chiziq allaqachon chizilgan — uni eshik oldiga surib to‘g‘rilang. Tizim shu chiziqni kesib o‘tgan odamlarni sanaydi, shuning uchun u haqiqatan odamlar o‘tadigan joyda bo‘lishi kerak.

Chiziq: ikki nuqtani bosing. Zona: burchaklarni bosing, oxirida ikki marta bosing. O‘ng tugma — o‘chiradi. Nuqtani sudrab ko‘chirish mumkin. Yashil o‘q do‘kon ichkarisini ko‘rsatadi.

Oxirgi sozlamalar

Bularni keyin ham o‘zgartira olasiz.

Do‘kon ish vaqti

Ikkalasi kiritilsa, ish vaqtidan tashqari harakat aniqlanganda ogohlantirish keladi. Bo‘sh qoldirsangiz bu tekshiruv o‘chiq turadi.

Telegram xabarlari (hozircha tayyor emas)

Bu funksiya hali ishlamaydi. Telegram xabarlarini cloud yuboradi, dastur esa hozir cloudga ulanmagan. Token kiritsangiz ham xabar kelmaydi — u faqat saqlanadi va cloud ulanganda ishga tushadi. Bugungi kunda barcha hodisalarni shu kompyuterdagi panelda ko‘rasiz.
Baribir hozir kiritib qo‘yaman

Telegramda @BotFather ga /newbot yozing — u token beradi. Chat ID ni olish uchun @userinfobot ga /start yuboring.

Cloudga ulash

Bu qadam ixtiyoriy. Ulanmasangiz ham tizim to‘liq ishlaydi — hisobot shu kompyuterda ko‘rinadi. Ulasangiz uch narsa qo‘shiladi.

  • Mijoz o‘z telefonidan ko‘radi — istalgan joydan, brauzer orqali
  • Telegramga ogohlantirish — kamera yopilsa, navbat uzaysa
  • Masofadan yangilash — yangi versiyalar o‘zi o‘rnatiladi
