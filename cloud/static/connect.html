Qurilmani ulash

Qurilma bor ekan, qolganini biz qilamiz

Agar qurilma yoningizda bo‘lsa, telefon raqamingizni qoldiring. Mutaxassis ulanish kodini beradi va masofadan ulashga yordam beradi.

Telefon raqam qoldirish

Mutaxassis uchun tezkor ulash (Linux qurilma)

Bu bo‘lim faqat ENES xodimi yoki texnik mutaxassis ulanish kodini berganidan keyin, Linux qurilma uchun ishlatiladi. Do‘kondagi Windows kompyuter uchun esa oddiy o‘rnatuvchi bor — o‘rnatish yo‘riqnomasi.

Ulanish kodini kiriting.

Ulanishdan keyin

  1. Qurilmani internetga ulang.
  2. Mutaxassis qurilmani cloud’ga biriktiradi.
  3. Kamera, NVR, tarif va funksiyalar masofadan sozlanadi.

Bu jarayon model o‘rnatmaydi. Hozir faqat qurilma autentifikatsiyasi, cloud aloqasi va monitoring sozlanadi.
