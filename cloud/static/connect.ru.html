Если устройство рядом с вами, оставьте номер телефона. Специалист выдаст код подключения и поможет подключить удалённо.

Быстрое подключение для специалиста (Linux-устройство)

Этот раздел используется только для Linux-устройства и после того, как сотрудник ENES или технический специалист выдал код подключения. Для компьютера с Windows в магазине есть обычный установщик — инструкция по установке.

Введите код подключения.

После подключения

  1. Подключите устройство к интернету.
  2. Специалист привяжет устройство к облаку.
  3. Камеры, NVR, тариф и функции настраиваются удалённо.

Этот процесс не устанавливает модель. Сейчас настраиваются только аутентификация устройства, связь с облаком и мониторинг.
