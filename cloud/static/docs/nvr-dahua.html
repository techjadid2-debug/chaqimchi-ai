Dahua / IMOU NVR

Odatda dastur hammasini o'zi topadi. Bu sahifa qo'lda kiritish kerak bo'lgan holatlar uchun.

RTSP manzil formati

rtsp://LOGIN:PAROL@NVR_IP:554/cam/realmonitor?channel=1&subtype=1
ParametrMa'nosi
channel=1Kanal raqami (1, 2, 3…)
subtype=0Asosiy oqim (og'ir — kerak emas)
subtype=1Substream (yengil — shuni ishlating)

ONVIF yoqish

NVR menyusi: Network → Access Platform → ONVIF → yoqing. Dahua'da ONVIF porti ko'pincha 80 yoki 8000 — dastur ikkalasini ham o'zi sinaydi.

Substream sozlash

Camera → Encode → Sub Stream: kodek H.264, o'lcham 704×576 (D1) yoki kichikroq, 10–15 fps. «Smart Codec / H.264+» ni o'chirib qo'ygan ma'qul — ayrim pleyerlar bilan mos kelmaydi.

Muhim

Dahua NVR bir vaqtda cheklangan RTSP ulanish beradi. Bitta kanalni bir nechta dasturda ochib qo'ymang — «tasvir kelmadi» chiqadi.
