Odatda dastur hammasini o'zi topadi. Bu sahifa qo'lda kiritish kerak bo'lgan holatlar uchun.

Paroldagi maxsus belgilar (@, /, :) muammo chiqarsa — dastur ustasida login-parolni alohida maydonlarga kiriting, u o'zi to'g'ri kodlaydi.

ONVIF yoqish (avtomatik topish uchun)

NVR menyusi: Configuration → Network → Advanced Settings → Integration Protocol → «Enable ONVIF» belgilang va foydalanuvchi qo'shing (Media huquqi bilan). Ayrim modellarda ONVIF alohida foydalanuvchi talab qiladi — admin login bilan ishlamasa shu sabab.

Substream sozlash

Configuration → Video/Audio → Sub-stream: kodek H.264 (H.265 emas!), o'lcham 640×360 yoki 640×480, 10–15 fps. H.265 substream tahlil kompyuterida ochilmasligi mumkin — bu eng ko'p uchraydigan «tasvir kelmadi» sababi.

Port

RTSP standart port: 554. NVR'da o'zgartirilgan bo'lsa (Network → Ports) manzilda o'sha portni yozing.
