Windows kompyuterga o'rnatish

Kerak: Windows 10/11 (64-bit), 8 GB RAM, internet. Oddiy ofis kompyuteri (masalan, Core i5) 4 kamerani bemalol ko'taradi.

1. Yuklab olish va o'rnatish

dl.chaqimchi.uz dan o'rnatuvchini yuklab oling va ishga tushiring: «Keyingi → Keyingi → Tayyor». O'rnatuvchi hamma keraklisini o'zi olib keladi (AI modellari, video kutubxonalari) — qo'shimcha dastur kerak emas.

O'rnatishda «Kameralarni avtomatik topish (tarmoq ruxsati)» bandini belgilangan holda qoldiring — usiz tarmoqdagi kameralarni qidirish ishlamaydi.

2. Sozlash ustasi

O'rnatilgach brauzerda http://127.0.0.1:8760 ochiladi (yorliq ish stolida ham bor). Ustada:

1. «Kameralarni qidirish» — tarmoqdagi kamera/NVR'lar ro'yxati chiqadi. Ko'p NVR o'zini e'lon qilmaydi — bu holda NVR IP manzilini qo'lda kiriting.
2. NVR login-parolini kiriting (NVR menyusidagi bilan bir xil).
3. «Shu NVR'dagi barcha kameralarni topish» — kanallar birma-bir tekshiriladi va tasvirlari ko'rsatiladi.
4. Har kameraga nom bering («Kirish», «Kassa») va saqlang.

3. Kirish chizig'ini chizish

Ustaning geometriya qadamida kirish eshigi ko'rinadigan kamerada eshik ostiga chiziq torting. Odam chiziqni kesib o'tsa — «kirdi» yoki «chiqdi» sanaladi. Chiziq to'g'ri turgan bo'lsa hisobot birinchi soatdayoq to'la boshlaydi.

4. Cloudga ulash

Sizga berilgan 6 belgili ulanish kodi bilan dastur cloudga o'zi ulanadi (kod o'rnatish havolasida bo'lsa hech narsa kiritmaysiz). Shundan keyin hisobotlar mijoz panelida va Telegram botda ko'rinadi.
