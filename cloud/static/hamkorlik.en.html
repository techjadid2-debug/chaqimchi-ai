Partnership

For camera installers — become an ENES partner

What we offer

You install cameras and NVRs in shops — we make those cameras smart: entry and exit counting, queue monitoring, security alerts, Telegram reports. Extra value for your customer, extra income for you.

How it works

1. Register in the partner panel; we approve you. 2. Tell us about your customer — we open the site and issue a pairing code. 3. Install the app on the shop's Windows PC and connect with the code. 4. Set up cameras and lines in the panel. Usually 45–90 minutes: less if the NVR is ready, more if RTSP and the network need work.

What you will need

A Windows 10/11 PC in the shop (an ordinary office PC is enough), an NVR or IP cameras (Hikvision, Dahua and others — ONVIF/RTSP), internet. Technical guides are ready; if something goes wrong you talk to us directly.
