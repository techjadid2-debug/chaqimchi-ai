Hikvision, Dahua va boshqa tizimlar bilan moslik

Chaqimchi brendga emas, lokal RTSP video oqimiga ulanadi. Quyidagi formulalar keng tarqalgan, lekin har bir NVR/kamera modeli va firmware’i obyektning o‘zida stream-probe bilan tekshiriladi.

RTSP orqali ulanadi

Hikvision / HiLook

1-kanal substream uchun odatiy formula:

rtsp://USER:PASS@NVR_IP:554/Streaming/channels/102
RTSP orqali ulanadi

Dahua

1-kanal substream uchun odatiy formula:

rtsp://USER:PASS@NVR_IP:554/cam/realmonitor?channel=1&subtype=1
Probe shart

ONVIF / boshqa brend

RTSP yoki ONVIF Profile S/T stream URI bo‘lsa ulash mumkin. Avtomatik ONVIF qidiruv hali tayyor emas; hozir RTSP manzil qo‘lda kiritiladi.

Mos emas yoki adapter kerak

Faqat cloud/USB/koaksial

Lokal RTSP bermaydigan cloud-kamera mos emas. Analog kamera faqat RTSP chiqaradigan DVR/NVR orqali ulanadi; USB kamera hozir qo‘llanmaydi.

Qabul profili: H.264 substream, 1280×720 gacha, RTSP over TCP, alohida faqat ko‘rish huquqidagi kamera foydalanuvchisi. H.265+, Smart Codec va ishlab chiqaruvchining yopiq protokoli kafolatlanmaydi.

Linux va Windows o‘rnatish holati

Tayyor

Ubuntu Server 24.04 LTS

Rasmiy bir qatorli curl buyrug‘i, systemd avtomatik xizmati va Cloud pairing to‘liq ishlaydi.

Tayyor

Windows 11 x64 / Windows 10

Rasmiy o‘rnatuvchi (chaqimchi-windows-<versiya>.exe): Keyingi → Keyingi → Tayyor. Python va AI modeli ichida, o‘rnatish uchun internet talab qilinmaydi. O‘rnatgach brauzerda bulut paneli ochiladi — kamera qidirish, kadrni tekshirish va chiziq chizish endi o‘sha yerda, ya’ni do‘kon kompyuteri oldida o‘tirish shart emas. Lokal sehrgar (localhost:8760/setup) usta rejimi sifatida qoladi: internetsiz o‘rnatishda va murakkab NVR uchun.

1

Uskuna va tarmoqni ulang

  1. NVR, router va N100 mini-kompyuterni uzluksiz elektr manbaiga ulang.
  2. NVR hamda Sotqinni bir router yoki switch’ga Ethernet kabel bilan ulang.
  3. NVR monitorida barcha kameralar ishlayotganini tekshiring.
  4. Router internetga chiqishini va DHCP manzil berayotganini tekshiring.
  5. NVR’da alohida faqat live-view huquqiga ega Chaqimchi foydalanuvchisini yarating.
Muhim: NVR paroli va RTSP manzilini oddiy chatga yubormang. Ular faqat o‘rnatuvchi panelidagi himoyalangan forma orqali kiritiladi.
2

Ubuntu va rasmiy paketni o‘rnating

  1. Mini-kompyuterga Ubuntu Server 24.04 LTS o‘rnating.
  2. O‘rnatishda kuchli lokal parol yarating va avtomatik vaqt mintaqasini tekshiring.
  3. Terminalda zarur paketlarni tayyorlang:
sudo apt update sudo apt install -y curl ca-certificates python3 python3-venv

So‘ng paneldagi obyektni oching. Panel siz uchun cloud manzili va 6 xonali pairing kodi qo‘shilgan tayyor buyruq beradi.

curl -fsSL https://CLOUD/downloads/sotqin-installer.sh | sudo bash -s -- --cloud https://CLOUD --code ABC123
3

Cloud, kameralar va mijozni bog‘lang

  1. O‘rnatuvchi panelida kamera-01…kamera-04 nomi va NVR substream RTSP manzilini kiriting.
  2. Pairing buyrug‘ini bajaring; kod bir marta ishlaydi va 48 soatda eskiradi.
  3. Panelda Sotqin online, kameralar esa online bo‘lguncha kuting.
  4. Mijoz loginini admin yaratadi. Mijoz o‘z panelida qurilma, kamera, hodisa va obuna holatini ko‘radi.
